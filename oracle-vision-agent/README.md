# وكيل الرؤية البصرية الذكي على خادم أوراكل (Oracle Qwen2.5-VL Vision Agent)
### المدينة الطبية بجامعة الملك سعود (KSUMC) - منصة رصد لجولات السلامة

تم بناء هذا الوكيل المستقل (`oracle-vision-agent`) لحل مشكلة استنزاف وتوقف `Gemini 2.5 API` في **"الراصد البصري الذكي للسلامة الميدانية"**، مع الحفاظ التام على استضافة ومزامنة المنصة الحالية على **Firebase**.

---

## 1. كيف يعمل الوكيل الذكي؟ (نظام الـ 3 طبقات)

عندما يلتقط المفتش الميداني صورة أو عدة صور في "الراصد البصري الذكي":
1. **الطبقة الأولى (Qwen2.5-VL Cloud API - سرعة 2-3 ثوانٍ):**
   - يتصل الوكيل بنموذج **`Qwen2.5-VL-72B-Instruct`** (عبر OpenRouter المجاني/المدفوع أو Alibaba DashScope الرسمي) مع تدوير تلقائي لعدة مفاتيح (`QWEN_API_KEYS`).
2. **الطبقة الثانية (Ollama المحلي على خادم أوراكل - مجاني 100% بلا حدود):**
   - يعمل نموذج **`qwen2.5vl:3b`** (أو `7b`) داخل رام خادم أوراكل نفسه (24GB RAM) بدون أي مفاتيح خارجية أو حدود استخدام.
3. **الطبقة الثالثة (مجمع مفاتيح Gemini الاحتياطية - Key Rotation Pool):**
   - يدعم إدخال عدة مفاتيح Gemini مفصولة بفاصلة (`GEMINI_API_KEYS`) للتبديل التلقائي الفوري في أجزاء من الثانية عند وصول أي مفتاح للحد الأقصى (`429 Quota Exceeded`).

بالإضافة إلى:
- **ضغط وتحجيم تلقائي للصور (أقصى بُعد `1024px`)** لتقليص استهلاك الـ Tokens بنسبة 80%.
- **ذاكرة تخزين مؤقت (SHA-256 Image Cache)** لمدة 30 دقيقة تمنع استهلاك الرصيد عند إعادة فحص نفس الصورة.

---

## 2. تجربة الوكيل محلياً الآن على جهازك (`F:\RSD-KSU`)

1. افتح المجلد `F:\RSD-KSU\oracle-vision-agent` وعدّل الملف `.env` لوضع مفتاح `QWEN_API_KEYS` (من [OpenRouter](https://openrouter.ai/keys) أو Alibaba Cloud) أو مفاتيح `GEMINI_API_KEYS`.
2. شغّل الملف:
   ```bat
   start-agent-windows.bat
   ```
   سيعمل الوكيل على الرابط: `http://localhost:8000`
3. شغّل منصة رصد من المجلد الرئيسي `F:\RSD-KSU` عبر `start-local.bat`، ثم افتح **"الراصد البصري الذكي"**:
   - ستجد في أعلى نافذة الراصد زر **⚙️ وكيل أوراكل / Qwen** لضبط وفحص الاتصال مباشرة من المتصفح!

---

## 3. خطوات إنشاء وتشغيل خادم أوراكل الجديد (Oracle Cloud Always Free)

### الخطوة 1: إنشاء الخادم (Instance) في Oracle Cloud
1. ادخل إلى حسابك في **Oracle Cloud Console** واختر **Compute -> Instances -> Create Instance**.
2. اختر نظام التشغيل (Image): **Canonical Ubuntu 22.04 أو 24.04**.
3. اختر المعالج والرام (Shape): **Ampere `VM.Standard.A1.Flex`** وحدد **4 OCPUs** و **24 GB RAM** (ضمن باقة Always Free المجانية مدى الحياة).
4. في إعدادات الشبكة (Security List / Ingress Rules)، افتح المنفذين **`80` (HTTP)** و **`443` (HTTPS)** و **`8000`**.

### الخطوة 2: رفع وتشغيل الوكيل بأمر واحد
ارفع مجلد `oracle-vision-agent` إلى الخادم الجديد، ثم نفّذ الأوامر التالية عبر SSH:
```bash
cd oracle-vision-agent
chmod +x setup-oracle-ubuntu.sh
./setup-oracle-ubuntu.sh
```
سيقوم السكربت تلقائياً بـ:
- تثبيت Python و FastAPI و Nginx.
- تثبيت **Ollama** وتحميل نموذج الرؤية البصرية **`qwen2.5vl:3b`**.
- إنشاء خدمة النظام `ksumc-vision-agent.service` لتعمل تلقائياً 24/7 حتى بعد إعادة تشغيل الخادم.

### الخطوة 3: ربط المنصة بالخادم الجديد
- افتح نافذة **"الراصد البصري الذكي"** في المنصة واضغط على زر **⚙️ وكيل أوراكل / Qwen** في الأعلى، وضع عنوان الخادم الجديد (`http://<ORACLE_SERVER_IP>`)، أو ضعه كقيمة افتراضية في `oracleAgentUrl` داخل `assets/js/ksu-ai-client.js`.
