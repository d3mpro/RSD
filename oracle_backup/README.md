# أرشيف نسخة خادم أوراكل (Oracle Cloud Archive)
## منظومة السلامة الميدانية - المدينة الطبية بجامعة الملك سعود (KSUMC)

تم إنشاء هذا المجلد لحفظ كافة الملفات البرمجية الخاصة بخادم أوراكل الرياض وتكامله الميداني للرجوع إليه مستقبلاً عند الحاجة.

### محتويات الأرشيف:
1. `assets/js/ksu-oracle-realtime.js`:
   - محرك المزامنة اللحظية عبر الويب سوكت (WebSockets) وواجهات REST API الخاصة بسيرفر أوراكل بالرياض.
2. `backend/app.py`:
   - كود خادم FastAPI المركزي لمنظومة السلامة الميدانية الذي كان يعمل على خادم أوراكل سحابياً (منفذ 8000/8001) متصلاً بقاعدة بيانات SQLite WAL.

### الحالة الحالية للمشروع:
- تم التحول بالكامل للاعتماد الحصري على **Firebase** (Firebase Realtime Database + Firebase Hosting).
- جميع الجولات والتفتيش والبلاغات وسجلات الورديات والاعتمادات لسباهي تُدار لحظياً وبكفاءة 100% عبر Firebase.
